## Card DSL v3 (`packages/cards/src/types.ts`; additive)
- `CardType` += `'identity'` (never in a deck; one per side). All cards gain `faction: 'haas_bioroid' | 'jinteki' | 'nbn' | 'weyland' | 'anarch' | 'criminal' | 'shaper' | 'neutral'` and `influence?: number` (pips; absent = 0). Identity fields: `minDeckSize`, `influenceLimit`, `link?` (shown only; traces later).
- `whenYouInstall?: {firstEachTurn: true, types?: CardType[], effects}` (HB: `gain_credits 1`). `installDiscount?: {amount, firstEachTurn: true, types}` (Kate: 1, `['program','hardware']`, min cost 0). Both read from **active sources** = the side's identity + its face-up installed cards (rig; rezzed Corp cards).
- `onRez?: Effect[]` (any Corp card, when it turns face up: action-phase rez, approach rez, free rez). Adonis: `onRez place_credits 12`, `onTurnStart take_credits 3`, `trashWhenEmpty` (now valid on Corp cards → Archives face up).
- Effects: `gain_clicks{amount}` (owner) · `brain_damage{amount}` · `trash_installed{types: RunnerCardType[]}` (trash 1 Runner card of those types, **Corp chooses**). `CardAbility` on rezzed Corp cards (Melange: click 3, `gain_credits 7`, label "Gain {gain} credits"); `abilityGain` also sums `gain_credits` (Magnum Opus "Gain {gain} credits", click 1).
- `BreakerAbility.break.count: 1 | 2` (Battering Ram: cost 2, barrier, count 2; strength +1 for 1, `until: 'encounter'`).
- `trashPrevention?: {types: CardType[]}` = "Trash this card: prevent an installed card of these types from being trashed" (Sacrificial Construct: program, hardware).
- **P1 face-down rule:** a face-down Corp card is never an active source and never triggers (`onTurnStart`, abilities, `whenYouInstall`, `installDiscount`). Corp cards may not have `onInstall` (data test) — Corp installs are face down.
- Decks: `DeckDef = {identity, cards: DeckList}`; `CORP_CORE_DECK`, `RUNNER_CORE_DECK` (proposal tables, + Rototurret ×2 replacing 1 Wall of Static + 1 Enigma — pm to confirm). `checkDeck(deck, {minDeckSize})` → problems `too_small | wrong_side | identity_in_deck | too_many_copies (>3) | agenda_faction | influence (> limit) | agenda_points` (Corp points in `[2·⌊size/5⌋+2, +1]` = 14–15 for 30). `HOUSE_MIN_DECK_SIZE = 30` (real rule 45; owner 2A). New ids: c13 HB identity, c14 Adonis, c15 Melange, c16 Biotic Labor, c17 Viktor 1.0, c18 Heimdall 1.0, c19 Rototurret; r13 Kate, r14 Sure Gamble, r15 Magnum Opus, r16 Pipeline, r17 Battering Ram.

## Engine interface (pinned; E1 copies it to `packages/engine/README.md` "Sprint 8 interface")
- **Options/state**: `GameOptions.deckSet: 'core' | 'starter'` (default `'core'` = 30-card decks + identities; `'starter'` = the Sprint 7 15/17-card decks, **no identities**, a frozen test fixture). `PlayerState` += `identity: string | null` (card id), `brainDamage: number`, `installedThisTurn: CardType[]` (reset for both at every `turn_started`; **never in any view** — it would reveal face-down Corp types). `RunState.firing: number | null` (sub being resolved when a choice opened). `ChoiceKind` += `'trash_target' | 'prevent_trash'`; `ChoiceState` += `target?: uid`, `resume: 'action' | 'run'`. Identity uids are fixed: `'id:corp'`, `'id:runner'`.
- **Rules**: `maxHandSize(s, side)` = 5 − brainDamage (discard step uses it). Runner `end_turn` with max < 0 → `game_over{corp, flatline}` (no discard step). Brain damage: +amount to `brainDamage`, then random Grip cards (seeded RNG) to the Heap; more than the Grip → flatline (as net damage). `installCost` applies `installDiscount` when no card of its `types` is in `installedThisTurn` (first matching install uses it up, even a free one). HB trigger: after `card_installed` (+ any `onInstall`) when `installedThisTurn` was empty. Turn start order: `turn_started` → reset → `onTurnStart`/refills (Adonis takes 3; empty → trashed; remote pruned) → Corp draw.
- **Choices inside a run** (Rototurret): `trash_installed` with 0 candidates does nothing (amount 0); with 1 the target is fixed (no window); with ≥ 2 → `choice_opened{trash_target, player: corp, cardId: ICE}`, `phase: 'choice'`, `run` **kept** (step stays `encounter`, `firing` = sub). If the target has a preventer in the rig (`trashPrevention` covers its type, not itself) → `choice_opened{prevent_trash, player: runner, cardId: ICE, target}`. On close: phase back to `'run'`, `subroutine_resolved` for `firing` (amount 1 trashed / 0 saved), then the remaining subs fire. A trashed breaker's boosts are dropped.
- **Actions**: new `{type:'choose', player, uid}` — `trash_target`: a candidate program uid; `prevent_trash`: a preventer uid. Checks: invalid_action → game_over → not_your_turn (`waitingOn`) → wrong_phase (no open choice of these kinds) → bad_target. `pass` in `prevent_trash` = let it be trashed; in `trash_target` = `bad_target` (mandatory). `rez` in a non-`free_rez` choice = `wrong_phase`. `use_ability` += `subs?: number[]` — required for `count: 2` (1–2 distinct unbroken subs, ascending; `sub` absent), forbidden for `count: 1` (`invalid_action`); one payment, one `subroutine_broken` per sub.
- **Events** (all public): `ability_triggered.trigger` += `'install' | 'install_discount' | 'rez'` (uid may be an identity uid; `install_discount` only when it lowered the price, before `credits_spent`) · `clicks_gained{player, amount}` · `brain_damage{amount, cardIds, maxHandSize}` · `corp_card_trashed{uid, cardId, server}` (Archives face up) · `trash_prevented{uid, cardId, byUid, byCardId}` · `choice_opened.target?`. Rototurret flow: `subroutine_fired` → (`choice_opened`…`choice_closed`)* → `rig_card_trashed` (target, or the Construct then `trash_prevented`) → `subroutine_resolved{op:'trash_installed'}`.
- **View**: `PlayerSideView` += `identity: {uid, cardId} | null`, `maxHandSize`, `brainDamage`. `CardOption` += `discount?` (credits off, > 0). `ChoiceView` += `target?`; options: `trash_target` = one `choose` per candidate (rig order); `prevent_trash` = one `choose` per preventer, then `pass`. `view.run` stays set while an in-run choice is open. `installedOptions` (Corp) lists rezzed-card click abilities (Melange). Breaker options for count 2: one per subset of unbroken subs of size 1–2 (Heimdall: 6).
- **Protocol**: test-mode `create.test` += `deckSet?` (production ignores it; always `'core'`). `PROTOCOL_VERSION` stays 1.

- QA-S7-1: hosted-credit pill never covers name/type at 640×360 (move into the art area / shrink type line). QA-S7-2: hosted credits = credit colour + coin icon; advancement = a different colour + chevron icon.
