# Sprint 5 tech plan (architect)

Scope: S-05-1..4 (read accessed cards, ICE says what it does, hand carousel, release publishing). Owner answers 1A (carousel), 2A (message stays until tapped), 3A (DECISIONS 2026-11-13). engine-dev (`sprint-05-engine`) and ui-dev (`sprint-05-ui`) start **at the same time**; only U4/U5 wait on E1. Contract changes go through the architect. `android.yml` keeps triggering only on `main` and `sprint-[0-9][0-9]`.

## Engine contract (E1, pinned; README "Sprint 5 interface")
- **Subroutine outcome** (`events.ts`): `SubOutcome = { sub: number; op: Effect['op']; amount: number }`. `amount` = the actual size: clicks really lost ("if able", may be 0), net damage dealt (printed), credits gained, cards drawn; 0 for `end_run`.
- **Event** `subroutine_resolved{iceUid, cardId, outcome: SubOutcome}`: pushed right after each fired subroutine's own effect events (after `clicks_lost`/`net_damage`, before `run_ended`/`game_over`). Public (the ICE is rezzed). `subroutine_fired` unchanged.
- **Preview** `RunView.letFire: { iceCardId: string; outcomes: SubOutcome[]; ends: 'run' | 'game' | null } | null`. Non-null only in the **Runner's** view at step `encounter` with rezzed ICE while `pass` is offered. `outcomes` = what `pass` would resolve now, in order, stopping after the one that ends the run/game; `ends` = `'run'` (ended by ICE), `'game'` (flatline), `null` (run goes on; `outcomes: []` = all subroutines broken). Computed by running the real resolution on a throw-away copy of the state (same code path, so label = result); exposes no hidden info (no discarded card ids). **The client never works out what ICE will do.**
- **Last run** `GameState.lastRun: { server, cards: {cardId, from}[] } | null`: set to `{server, cards: []}` at `run_started` (replaces the previous one), a card appended at each `card_accessed` (access order, stolen/trashed/left all kept), set to `null` when the Runner's turn ends (`turn_ended` runner, incl. after discard). `PlayerView.lastRun: { server, cards: {cardId, from}[] } | null` = Runner's view only, only when no run is in progress and `cards.length > 0`; always `null` for the Corp. No new events or actions. RULES_SPEC § Runs step 4 gains: "the Runner may look back at them (Last run) until his turn ends; the Corp is shown nothing new".
- Stolen agendas (`players.runner.scored`) and face-up Archives (`discard` non-null entries) are already in the view: zooming them is client-only.

## Release publishing contract (U2)
`apps/android/scripts/publish-release.mjs` (Node, `gh` runner injectable for tests), called by `android.yml`. Never delete before the new APK is up: `gh release view TAG` → if "release not found" create it at `GITHUB_SHA`; any other error **fails**. If it exists: `upload --clobber` the new APK → move the tag to `GITHUB_SHA` (git refs API, `force`) → `release edit` title/notes/prerelease/latest → delete the **other** `.apk` assets. Every failed `gh` call exits non-zero (no `|| true`, no `2>/dev/null`). Workflow: `build` job (concurrency `android-build-<ref>`, cancel in progress) uploads the APK artifact; `publish` job (`needs: build`, concurrency `android-publish-<ref>`, **no** cancel in progress) downloads and publishes. Invariant: at every step the release has ≥ 1 APK.

## Test strategy
Engine: Vitest per AC and per new field/event, the preview property test, hidden-info tests (Corp never gets `lastRun`/`letFire`). Client: unit tests for labels/report text and input; only the touched e2e specs (`docs/TESTING.md`), 3 sizes once before hand-off; 6× throttle only on the carousel swap spec. CI: the workflow run on `sprint-05` is the proof for S-05-4.

## Risks
Pre-drawing every zoom texture on a slow phone could delay the first zoom: nearest-first, one per frame, and the hold delay hides it; measure at 6×. The report overlay must not swallow the next real tap (consumed tap = only the dismiss). Moving a tag with the API while the release is published is untested here: the fake-`gh` test pins the call order; first real proof is the `sprint-05` run. Preview runs the resolver on a copy: any future effect with outside side effects would break purity (none exist; the engine is pure).
