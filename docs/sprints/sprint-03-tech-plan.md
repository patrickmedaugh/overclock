## Engine contract (E1, pinned)
- **State:** `phase` gains `'run'` (every Sprint 1/2 action → `wrong_phase` during a run). `GameState.run: RunState | null` (internal shape is engine-dev's; it holds server, position, step, broken subs, encounter/run strength boosts, `bypassNext`, `extraAccess`, the access list). `GameState.lastRunTurn: number | null` (turn a run was last *started*). `Installed.advancements: number` (0 default). `PlayerState.scoreArea: string[]` (card ids, face up). `WINNING_POINTS = 7`. `WinReason += 'agenda_points' | 'flatline'`.
- **Run steps** (`run.step`, `waitingOn` derived): `approach` (Corp: `rez`/`pass`) → `encounter` (Runner: `use_ability`…, `pass` = Let it through) → `continue` (Runner: `pass` = Continue / `jack_out`) → … → `access` (Runner: `steal`/`trash`/`pass` = Leave it / Done). Position walks `ice.length-1 … 0`, then the server.
- **Auto-pass (engine, never the client):** approach is skipped if the ICE is already rezzed (→ encounter) or the Corp can't pay its rez cost (→ passed, face down). Encounter ends by itself when every subroutine is broken or Inside Job's bypass applies (`ice_bypassed`). No `continue` stop before the first ICE or on a server with no ICE (straight to access). Encounter with no usable breaker still stops for **Let it through** (S-03-3 AC4 / S-03-4 AC4: the player sees what fires). Invariant test: outside `over`, exactly one side has legal actions.
- **Actions:** `run {player, server}` (1 click) · `rez {player, uid}` (uid = approached ICE; pays card `cost`) · `pass {player}` (the default at the current step) · `jack_out {player}` (`continue` step only) · `use_ability {player, uid, ability, sub?}` (breaker ability index; `sub` = subroutine index, required for breaks) · `steal {player, card}` / `trash {player, card}` (index into `run.access.cards`) · `advance {player, uid}` (1 click + 1 credit, own installed agenda) · `score {player, uid}` (no click, Corp action phase, advancements ≥ requirement) · `play` gains `server?` (run events with no fixed server, i.e. Inside Job).
- **Reasons:** `+ 'too_weak' | 'condition_not_met'`. Run decisions: `invalid_action → game_over → not_your_turn` (not the deciding side) `→ wrong_phase` (no run / wrong step) `→ bad_target` (bad uid/ability/sub/card, sub already broken, breaker type ≠ ICE type, Done with an unstolen agenda) `→ too_weak → no_credits`. `play`: `… bad_card → bad_target → not_implemented → condition_not_met → no_credits`.
- **Events:** `run_started{server, cardId?}`, `ice_approached{uid, position}`, `ice_rezzed{uid, cardId}` (public), `ice_encountered{uid}`, `ice_bypassed{uid}`, `strength_changed{uid, strength}`, `subroutine_broken{iceUid, sub, breakerUid}`, `subroutine_fired{iceUid, sub}`, `clicks_lost{player, amount}`, `net_damage{amount, cardIds}` (face up to Heap), `ice_passed{uid}`, `run_successful{server}`, `card_accessed{cardId, from}`, `agenda_stolen{cardId, points}`, `card_trashed{cardId, from}`, `run_ended{server, outcome: 'accessed'|'jacked_out'|'ended_by_ice'|'flatline'}`, `card_advanced{uid, advancements}`, `agenda_scored{uid, cardId, points}`; `credits_spent` for rez/break/pump/trash/advance; `game_over` with the new reasons. Corp projection drops `card_accessed.cardId` for R&D (deck order is hidden from the Corp too).
- **View:** `InstalledView.advancements` (both sides). `PlayerSideView.scored: string[]`, `points`. `PlayerView.runOptions: CardOption[]` (one `run` per server, Runner only). `PlayerView.installedOptions: Record<uid, CardOption[]>` (Corp: `advance` per installed agenda, `score` only once it has enough counters). `PlayerView.run: RunView | null` = `{server, position, step, waitingOn, iceUid, ice: {cardId|null, strength|null, subroutines: {text, broken}[]} | null, breakerStrength: Record<uid, number>, access: {cards: {cardId, from, stolen}[]} | null, extraAccess, bypassPending, options: CardOption[]}`; the Runner sees an approached ICE's `cardId` only once rezzed; `options` lists the viewer's offered moves at this step with engine `cost` and `reject` (same rules as `handOptions`). **The client never computes a price, a strength or what fires.**
- **Card DSL v1 (`packages/cards`):** `Effect += {op:'net_damage', amount} | {op:'lose_clicks', amount} | {op:'end_run'} | {op:'run', server?: ServerId, extraAccess?, bypassFirst?}` (damage/click loss always hit the Runner; `run` must be the last effect). ICE: `subroutines: {text, effect}[]`. Breakers: `abilities: ({op:'break', cost, iceType, count:1} | {op:'strength', cost, amount, until:'encounter'|'run'})[]`. Operations: `playIf?: 'runner_ran_last_turn'` (`lastRunTurn === turn − 1`). Corroder/Gordian/Ninja, the 4 ICE, Maker's Eye (`run rd, extraAccess 2`), Inside Job (`run, bypassFirst`), Neural EMP (`playIf`, `net_damage 1`) all as data; no card has `needs` any more. Corp deck +1 Hostile Takeover +1 Private Security Force (17 cards, 9 points; DECISIONS Q2 A).
- **Access:** HQ = 1 card picked with the seeded RNG; R&D = top 1 + `extraAccess`, one at a time (refs must survive a steal: test steal card 1, then card 2 is the original 2nd); remote = every card, one at a time; Archives = all cards as **one** group, all turned face up for good, agendas stealable, nothing trashable. Agendas offer only **Steal** (mandatory); cards with a trash cost offer `trash` (price, may be `no_credits`) + Leave it; others only Done. Net damage picks random hand cards with the seeded RNG; damage > hand size → discard all, Corp wins `flatline`.

## Risks
Run is the biggest state change yet: E3/E4 tests drive every step through `apply` only. Tap count per run (Continue stop after each ICE, Let it through without breakers): watch at demo. Hot-seat Corp prompt must not leak into the Runner seat view (E6 property test + U1 review). Real-card numbers now matter (breaker costs/strengths re-checked by architect, DECISIONS). CDP `timestamp` honoring is unverified: U0 probes it first, fallback named.
