Scope: S-02-1..6 (installs, ICE, Runner rig, play money/draw, real cards + words, landscape phones). S-02-4 slips first if short. Engine-dev lands E1 (types + README) first; ui-dev codes against it. ## Engine contract (E1, pinned)
- **State:** installed cards get instance ids `uid` (`"i1"`, `"i2"`, … from `state.nextUid`). Corp `servers: Server[]` = `hq`, `rd`, `archives`, then `remote1…` (`state.nextRemote`, never reused). `Server = {id, ice: Installed[] (index 0 innermost, new ICE pushed = outermost), content: Installed[]}`; `Installed = {uid, cardId, rezzed:false}`. Runner `rig: Installed[]` (install order). `MEMORY_LIMIT = 4` (engine constant; program `memory` from card data). `discard` entries become `{cardId, faceUp}` (played operations go to Archives face up; hand-limit Corp discards stay face down).
- **Actions:** `install {player, handIndex, server?: ServerId | 'new'}` (Corp: `server` required; Runner: must be absent). `play {player, handIndex}` (operation/event). Hand indices, not ids (duplicates share ids).
- **Rules (rules.ts table):** Corp agenda/asset → a remote with no agenda/asset, or `new`; upgrade → any server or `new`; ICE → any server or `new`, cost = ICE already on it. Corp non-ICE installs cost 0. Runner install cost = card `cost`; programs need `used + memory ≤ 4`. Each costs 1 click. New reasons and precedence: `invalid_action → game_over → not_your_turn → wrong_phase → no_clicks → bad_card` (index out of range / wrong type for the action) `→ bad_target → not_implemented` (card `needs:'runs'`) `→ no_credits → no_memory`.
- **Events:** `credits_spent{player,amount}`, `server_created{server}`, `card_installed{player, uid, zone:'ice'|'content'|'rig', server?, handIndex?, cardId?}`, `card_played{player, cardId, handIndex?}` then the effect's own `credit_gained`/`card_drawn` events. Opponent projection drops `handIndex` and, for Corp installs, `cardId`.
- **View:** `corpServers: ServerView[]` (`InstalledView{uid, cardId: string|null, faceUp}`; Runner sees `cardId:null` for every unrezzed Corp card), `rig`, `memory{used,limit}`, `discard: (string|null)[]` (null = face down to viewer), and `handOptions: CardOption[][]` per viewer hand index, `CardOption{action, cost, reject: RejectReason|null}`, listing every *offered* target (bad_card/bad_target excluded; no_credits/no_memory/not_implemented kept so the UI can show the price and the hint). **The client never computes a price, a target or memory.** `legalActions` order: draw, gain_credit, end_turn, discard, install…, play… (AI stub unchanged).
- **Card DSL v0 (`packages/cards`):** `onPlay?: Effect[]`, `Effect = {op:'gain_credits',amount} | {op:'draw',count}`, `needs?: 'runs'`. Draw effects stop at an empty deck (no loss; only the mandatory draw loses). No per-card code in the engine.
