## Engine interface (pinned; E1 copies it to `packages/engine/README.md` "Sprint 9 interface")
- **State**: `PlayerState.tags: number` (Runner; 0 for the Corp). `GameState.lastSuccessfulRunTurn: number | null` (set at `run_successful`). `ChoiceKind` += `'trace_corp' | 'trace_runner'`. `ChoiceState.trace?: TraceState = {base, strength: number | null /* base + Corp bid, null while the Corp bids */, corpBid: number | null, onSuccess: Effect[]}`; `cardId` = the ICE or operation.
- **Trace flow** (in a run: `resume:'run'`, `run.firing` = sub, as Rototurret; SEA Source: `resume:'action'`): `trace_started{cardId, base, link}` → Corp window → Runner window → `trace_resolved` → onSuccess effects → (in a run) `subroutine_resolved{op:'trace', amount: 1 success / 0 fail}` (before any `run_ended`/`game_over`, via `beforeEnd`) → remaining subs. Success iff **strength > link + Runner bid** (ties: Runner).
- **Windows are skipped when the bid cannot matter** (snappiness rule; all inputs public): Corp window opens iff Corp credits > 0 **and** base + credits > link. Runner window opens iff 0 < strength − link ≤ Runner max bid. A skipped side bids 0: `trace_bid{player, credits:0, auto:true}`, no `choice_opened`, no hand-off.
- **Bid limits**: Corp max = its credits. Runner max = credits + `run.tempCredits` (bad-publicity credits are spendable in a run, real rule; paid temp-first like breakers; recurring credits are icebreaker-only, not used).
- **Actions**: `{type:'trace_bid', player, credits}` — checks `invalid_action` (non-negative integer) → `game_over` → `not_your_turn` (`waitingOn`) → `wrong_phase` (no open trace choice) → `no_credits` (> max). `pass` in a trace choice = `bad_target` (bid 0 is the default). `{type:'remove_tag', player}` (Runner, 1 click + 2 credits): → `not_your_turn` → `wrong_phase` (own action phase) → `no_clicks` → `condition_not_met` (0 tags) → `no_credits`. `{type:'trash_resource', player, uid}` (Corp, 1 click + 2 credits): → `not_your_turn` → `wrong_phase` → `no_clicks` → `condition_not_met` (untagged) → `bad_target` (not a rig resource) → `no_credits`. `activate` accepts a **scored uid** `score:corp:<index>` (index into the Corp score area; `scoredUid(side, i)` exported); `requires:'runner_tagged'` → `condition_not_met`.
- **Events** (all public): `trace_started{cardId, base, link}` · `trace_bid{player, credits, total, auto?}` (after its `credits_spent`; total = strength for the Corp, link + bid for the Runner) · `trace_resolved{cardId, strength, total, success}` · `tags_changed{amount /* +n / −1 */, tags}` · `meat_damage{amount, cardIds}` (flatline as net damage) · `rig_card_trashed.cause?: 'tagged'` · `choice_opened/closed` with the new kinds. Hunter in a run: `subroutine_fired` → `trace_started` → (`choice_opened{trace_corp}` → `choice_closed` → `credits_spent`)? → `trace_bid{corp}` → (`choice_opened{trace_runner}` → `choice_closed` → `credits_spent`)? → `trace_bid{runner}` → `trace_resolved` → `tags_changed` → `subroutine_resolved` → `ice_passed`…
- **View**: `PlayerSideView` += `tags`, `link` (Corp: 0). `ChoiceView.trace?: {base, strength /* base until the Corp bid */, corpBid: number | null, link, runnerMaxBid, corpMaxBid, needed /* Runner window: credits to tie = escape */}`; options = one `trace_bid` per amount 0..max (`cost` = amount), deciding viewer only. `PlayerView.basicOptions: CardOption[]` — Runner: `remove_tag` (cost 2, `clicks:1`) **while tagged**, with `reject`; Corp: `[]`. Corp `installedOptions` += per rig resource uid a `trash_resource` option (cost 2, `clicks:1`) **only while the Runner is tagged**; += per scored agenda with `scoredAbilities` (key `score:corp:<i>`) its `activate` options, always listed (reject `condition_not_met` when untagged). `RunView.letFire` stops where a trace opens (as Rototurret).

## Client (rules-free: every number, limit and refusal comes from the view)
- **Bid panel** (choice `trace_*`): big number, −/+ (44 px+), **Max** (= highest offered bid), **Bid**; lines "Trace 3 · add credits? → strength 5" (Corp) / "Trace strength 5 · your link 1 · spend 4 to stop it" (Runner, from `needed`). In a run it lives in the run panel strip (Rototurret pattern); SEA Source in the Corp-turn choice panel. Result toast from `trace_resolved` ("Hunter: trace 5 vs link 5: Runner escaped" / "…: Runner tagged"); auto bids shown as "Corp bid 0".
- **Hand-overs**: in a run Runner → Corp → Runner; SEA Source Corp → Runner → Corp — through the existing `Decision`/cover. Online: "Corp is choosing its trace bid…" / "Runner is choosing his trace bid…".
- **Tags/link**: "Tagged N" marker by the Runner's credits (both screens; tap on own turn → "Remove 1 tag · 1 click + 2 credits" from `basicOptions`, dimmed with the reason); link shown with the identity/credits. Corp taps a Runner resource → "Trash · 1 click + 2 credits". PSF in the score area: tap → "Do 1 meat damage · 1 click", dimmed "Runner isn't tagged" (text keyed on `requires`). `meat_damage` reuses the net-damage flight + message naming the card. SEA Source dimmed "Runner made no successful run last turn" (keyed on `playIf`). Report texts for `trace` / `give_tags` subs; letFire line for a trace sub shows the sub text.

## Risks (cut order: SEA Source, then Ichi 1.0 — decks fall back, still legal; further cuts are the pm's call)
- **Two chained choices inside an ICE** (Ichi: trash, prevent, trash, prevent, then two trace windows) stress resumable subroutines; E6 tests every order, incl. flatline mid-sequence.
- **Skipped windows** might surprise the owner ("why didn't I get to bid?") — the toast always shows both bids; pm mentions it in the demo notes.
- **Pass-and-play hand-overs**: a Hunter trace in a run costs two covers; SEA Source two in the Corp's turn. Skips keep most traces at one or zero.
- **Online**: an away player still stalls a bid window (S-09-5 dropped by the owner; same as today's rez window).
- **Card text from memory** for the 2012 printing — engine-dev checks against `netrunner-cards-json` before E2 lands (list in DECISIONS).
