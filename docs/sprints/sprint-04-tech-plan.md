## Engine contract (E1, pinned)
- **Card DSL:** `CardDef.onScore?: Effect[]` (runs only on `score`, never on steal). `Effect += {op:'bad_publicity', amount} | {op:'free_rez', what:'ice'}` (`free_rez` opens a choice and must be the last effect). Hostile Takeover `onScore: [gain_credits 7, bad_publicity 1]`; Priority Requisition `onScore: [free_rez ice]`. Scoring that reaches 7 points ends the game first; `onScore` is skipped.
- **State:** `GameState.badPublicity: number` (Corp's, 0 at start). `RunState.tempCredits: number`. `Phase += 'choice'`; `GameState.choice: {kind:'free_rez', player:'corp', cardId} | null`. No choice opens if the Corp has no unrezzed installed ICE (auto-pass, no event).
- **Actions (none new):** in phase `choice`, `rez {player, uid}` = rez any unrezzed installed Corp ICE for 0 (no `credits_spent`); `pass {player}` = **Skip**. Every other action → `wrong_phase`; Runner → `not_your_turn`; uid not an unrezzed installed ICE → `bad_target`. `waitingOn(state)` / `hasMeaningfulResponse` return the Corp during a choice.
- **Bad publicity in runs:** at run start `tempCredits = badPublicity`. Runner costs during the run (break, pump, trash) are paid from temp credits first, then credits; affordability (`no_credits`, option `reject`, run auto-pass) uses credits + tempCredits. Left-over temp credits vanish at every run end (access, jack out, end the run, flatline, game over).
- **Events:** `credit_gained{player:'corp', amount:7}` (existing) · `bad_publicity_gained{amount, total}` · `choice_opened{kind:'free_rez', player:'corp', cardId}` · `ice_rezzed{uid, cardId}` (existing) · `choice_closed{kind, skipped}` · `temp_credits_gained{amount}` (right after `run_started`, only if > 0) · `credits_spent{…, temp?}` (`temp` = part of `amount` paid from temp credits) · `temp_credits_lost{amount}` (right before `run_ended`, only if > 0). All public. Order on score: `agenda_scored` → effects in card order.
- **View:** `PlayerView.badPublicity: number` (both). `RunView.tempCredits: number` (both). `PlayerView.choice: {kind:'free_rez', waitingOn:'corp', cardId, options: CardOption[]} | null`; Corp `options` = one `rez` per unrezzed ICE uid (cost 0) + one `pass`; Runner `options` = []. `legalActions` follow the same table. **The client never computes which ICE may be rezzed or how many credits a run has.**

## Android build contract (U2/U3)
- `vite build --mode android` → `apps/client/dist-android/`, `base: '/'` (Capacitor serves the web root at `https://localhost/`; web build keeps `/overclock/`). Compile-time defines: `__TEST_HOOK__` (false only in android mode; `main.ts` wraps the whole `window.__overclock` block in `if (__TEST_HOOK__)` so it is removed), `__NATIVE__` (true only in android mode; guards `@capacitor/app` via dynamic import), `__BUILD_TIME__` (`OVERCLOCK_BUILD_TIME` env, e.g. `2026-11-13 14:32 UTC`, else build time; shown small in a board corner on web and app). The android `index.html` drops `#rotate` (transformIndexHtml). Strict CSP unchanged.
- `apps/android` = workspace `@overclock/android` (no `build` script, so root `npm run build` never needs the Android SDK; scripts `sync`, `apk`). Exact pins: `@capacitor/cli`, `@capacitor/android`, `@capacitor/core` **8.6.2**, `@capacitor/app` **8.1.2** (`core`/`app` also exact in `apps/client`). appId `app.overclock.game` (never changes), name **OVERCLOCK**, `webDir: '../client/dist-android'`. Generated `android/` project committed.
- Manifest: `screenOrientation="sensorLandscape"`. MainActivity: hide status + navigation bars (`WindowInsetsControllerCompat`, swipe shows them briefly), re-applied on resume/focus; cutout `shortEdges`. Safe areas: use Capacitor 8 SystemBars CSS insets if the installed version provides them (check `node_modules/@capacitor/android` source), else MainActivity pushes cutout insets as `--oc-safe-*` CSS vars; `#safe-probe` uses `max(env(…), var(--oc-safe-*, 0px))`.
- Signing: one committed release keystore `apps/android/keystore/overclock.jks` (alias `overclock`, RSA 2048, 10000 days, made once by ui-dev with `keytool`). `versionCode` = `github.run_number` (env, default 1); `versionName` = build time.
- Workflow `.github/workflows/android.yml`: push to `main` / `sprint-*` (paths-ignore `docs/**`) + `workflow_dispatch`; `permissions: contents: write`; `GITHUB_TOKEN` via `gh`. Steps: node 20, `npm ci`, temurin JDK 21, set `OVERCLOCK_BUILD_TIME` once, android web build, bundle check, `cap sync`, `./gradlew assembleRelease`, then checks that fail the job: APK exists; `apksigner verify --print-certs` SHA-256 = pinned fingerprint; `aapt2 dump badging` shows package id, label OVERCLOCK, sensorLandscape. Publish: one **rolling release per branch**, tag `app-<branch>`: `gh release delete --cleanup-tag -y` (if any) then `gh release create` at this commit, title `OVERCLOCK app — <branch> — built <time>`, asset `overclock-<branch>-<YYYYMMDD-HHMM>.apk`, plain-language install notes in the body; `main` = Latest, `sprint-*` = prerelease. Concurrency per ref, cancel in progress.

## Test strategy
Engine: Vitest per AC and per reason, property tests above. Client: unit + only the touched e2e specs (`docs/TESTING.md`); 3 sizes once before hand-off. Android: the CI workflow's checks are the automated proof for S-04-1 AC1/AC5; real-phone ACs are owner checks at demo.

## Risks
No real Android device or SDK here: first install is on the owner's phone (notch/insets most likely to need a fix). Capacitor's bridge script is injected inline into `index.html` before our CSP `<meta>` (so allowed); if Back does nothing on the phone, check this first. Committed keystore means anyone with the repo could sign an update; acceptable for a personal app (DECISIONS). Rolling release deletes and recreates the tag each build (no history of old APKs; fine while games aren't saved). Free-rez choice is a new phase: every existing switch over `Phase` must handle it (E1 type check catches them).
